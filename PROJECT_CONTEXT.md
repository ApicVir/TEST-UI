# Project Context: Wholesale Order Board POC (v1)

This repository contains a front-end-only prototype for internal wholesale operations at babes-honey-farm.com.

## Purpose
- Replace weekly spreadsheet workflow with a clearer app flow while preserving sheet-like usability.
- Keep orders visible on the master board through status changes.

## v1 Guardrails
- No backend/database/auth.
- No external APIs or real integrations (FreshBooks and Google Forms are placeholders only).
- Mock data + local React state only.
- Focus screens: Order Board, Picklist/Delivery Runs, Print Preview, Order Detail modal.
- Product automation only for standard product grid columns; edge cases stay in notes/manual review.

## Not in Scope
Customer portal, AI assistant, CRM expansion, route optimization, advanced inventory, auto pricing or invoicing.
